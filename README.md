# Live Meters Support

Static support website for Live Meters. This repository contains website files only. Keep the app source in its separate private repository.

## GitHub Pages

Upload index.html, documentation.html, privacy.html, style.css, favicon.svg, and .nojekyll to the root of HoughtonAudio/Live-Meters-Support. Preserve any existing files that serve a purpose. In Settings → Pages choose Deploy from a branch, main, / (root). Save and verify the completed deployment.

Expected URLs after successful deployment:
- Support: https://houghtonaudio.github.io/Live-Meters-Support/
- Privacy: https://houghtonaudio.github.io/Live-Meters-Support/privacy.html

Use relative links to preserve the repository prefix. No build or dependencies are required.

Hosting reference: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
